


# Air Quality Index (AQI) Prediction Using Machine Learning

Complex Engineering Problem (CEP) | Introduction to Machine Learning  
Department of Electrical Engineering, Namal University, Mianwali

## Project Overview

This project predicts daily Air Quality Index (AQI) values for 2025 using historical air pollution data from 2018 to 2024. The dataset includes PM2.5, NO2, and SO2 measurements.

Random Forest and Gradient Boosting regression models were used for prediction. Current and previous-day (lag-1) pollutant values were used as input features. An LSTM model was also tested but showed lower accuracy.

## Machine Learning Models

- Long Short-Term Memory (LSTM)
- Random Forest Regressor
- Gradient Boosting Regressor
